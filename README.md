# 雕像探索自动化（StatueExplorer）

海岛奇兵「雕像探索（雕刻查询）」自动化工具。启动后自动完成登录、开弱网、
神龛选卡、研究加速、结果识别与记录的完整流程，四张卡（绿/蓝/红/紫）可以全部跑，
也可以只跑指定的一张。

## 主要功能

- 自动登录并进入主岛，自动导航到研究页面
- 自动控制弱网工具（QNET），模拟弱网环境
- 自动完成神龛选卡与研究加速的整套点击
- 自动识别每次探索结果（属性名 + 品质提升/研究代币）并写入记录文件
- 跑前自动替换游戏配置表，跑完自动还原，无需手动干预
- 内置环境检测：一键确认设备、游戏、分辨率、弱网工具是否就绪
- 提供图形界面（GUI），所有操作都能在界面上完成

## 快速开始

### 图形界面（推荐）

```bash
python main_statue_gui.py
```

在界面上设置循环次数、选择卡片，点「开始」即可运行：

- 「环境检测」：运行前先点一下，确认一切就绪
- 「设置坐标」：首次使用需要设置一次神龛/雕塑坐标（可手填，也可截取当前画面后在截图上直接点选），设置一次后自动保存，之后无需再动
- 弱网可以在界面上手动开关
- 运行日志和结果实时显示在界面上

### 命令行

```bash
python main_statue.py --x 2              # 四卡各跑 2 次（--x 必填）
python main_statue.py --x 2 --outer 1    # 只跑绿雕 2 次
python main_statue.py --check-env        # 只做环境检测
python main_statue.py --check-network    # 只检测弱网是否生效
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `--x` | 每张卡跑的次数（必填） |
| `--outer 1~4` | 只跑指定的一张卡：1 绿雕、2 蓝雕、3 红雕、4 紫雕 |
| `--rounds 1~4` | 从绿雕开始连跑几张卡（默认 4） |
| `--stop-after-research` | 测试用：进入研究界面后即停止 |
| `--check-env` | 只做环境检测 |
| `--check-network` | 只检测弱网 |
| `--no-patch-csv` | 本次运行不替换配置表 |

## 使用前准备

1. **模拟器**：MuMu 15 模拟器，分辨率设为 1280×720（横屏）
2. **弱网工具**：提前手动打开 QNET，并把悬浮窗拖到屏幕左下角；
   运行前确认弱网处于关闭状态（工具会检测并提示）
3. **依赖安装**：`pip install -r requirements.txt`
4. **首次使用**：在 GUI 的「设置坐标」里设置一次神龛/雕塑坐标

> ADB 地址（默认 `127.0.0.1:16384`）等如需修改，请编辑 `statue_auto/config.py`。

## 运行过程中

- 每次运行：环境自检 → 替换配置表 → 逐卡循环（登录 → 弱网 → 神龛 → 研究加速 → 识别结果 → 记录）→ 还原配置表
- 无论正常结束、手动停止还是出错退出，都会自动还原配置表、退出游戏并关闭弱网
- 识别失败的结果会记录为 `(error)`，不影响后续循环

## 结果记录

结果保存在 `records/` 目录下，每次运行生成一个新文件（文件名带时间戳，不会覆盖）。
文件为表格形式：每行一个次数，绿雕/蓝雕/红雕/紫雕各一列。
首行注释：`------S代表品质提升,B代表代币------`。

## 配置表手动操作

正常情况下配置表会自动替换和还原，无需关心。如果程序异常退出后游戏数据
状态不对，可以手动处理：

```bash
python -m utils.csv_patch status              # 查看当前状态
python -m utils.csv_patch restore --cleanup   # 还原配置表并清理备份
python -m utils.csv_patch replace             # 手动替换（一般不用）
python -m utils.csv_patch cleanup             # 只删除备份文件
```

## 常见问题

- **提示设备不可用**：确认 MuMu 模拟器已启动，ADB 地址正确
- **提示分辨率不符**：把模拟器分辨率改为 1280×720
- **提示弱网工具未就绪**：打开 QNET，把悬浮窗拖到屏幕左下角，并确认弱网是关闭状态
- **提示请先设置坐标**：首次使用，先在 GUI 里完成一次「设置坐标」
